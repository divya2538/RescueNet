# RescueNet

RescueNet is a smart road safety and emergency assistance web application developed for the Road Safety Hackathon 2026 organized by IIT Madras.

The platform helps users during road emergencies by providing quick SOS support, emergency contact alerts, nearby hospital access, road issue reporting, and AI-based emergency assistance.

## Features

- SOS Emergency System
- Live Location Detection
- WhatsApp Emergency Alert
- Nearby Hospital Navigation
- Road Issue Reporting
- Traffic Rules and Fine Awareness
- AI Emergency Assistant

## How the SOS System Works

1. User enters an emergency contact number
2. User clicks the SOS button
3. The application detects live GPS location
4. A Google Maps link with nearby hospitals is generated
5. WhatsApp opens automatically with an emergency alert message
6. Emergency contact receives the live location and alert information

## Technologies Used

- HTML
- CSS
- JavaScript
- Geolocation API
- Google Maps
- WhatsApp URL Integration
